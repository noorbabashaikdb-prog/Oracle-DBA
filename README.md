Oracle-DBA-Notes — Word Document Study Pack
This package converts the Oracle DBA repository structure into separate Word documents for Theory and Practical learning.
Document pattern
Each module contains:
`01_<module>_Theory.docx` — definitions, architecture, concepts, interview points.
`02_<module>_Practical.docx` — SQL/Linux commands, procedures, validation and scenarios.
`<module>_diagram.png` — visual architecture/process diagram where applicable.
